# Fewer Users, More Value: A NEAR Investment Thesis

**NEAR Hackathon 2026 — Track 02: Investment Thesis**

DAA fell 46%. Value per transaction doubled. Activity per account rose 52%. Contract deploys quadrupled. This is either a chain dying or a chain concentrating. We built a dashboard to figure out which.

**[Live dashboard →](https://tofunmi-baller.github.io/near-investment-thesis/)** · **[Read the full thesis →](./THESIS.md)**

## Quick Start

```bash
# Install
pip3 install requests
cd dashboard && npm install

# Fetch real data + build (no credentials needed)
cd .. && make rebuild

# Serve locally
make serve
# Open http://localhost:4173
```

One command (`make rebuild`) fetches live data from the NEARBlocks public API and builds the dashboard. No API keys, no BigQuery credentials, no authentication.

## Data Integrity

- **Real data:** All NEAR metrics come from `api.nearblocks.io/v1/charts` and `/v1/stats` (2,300+ days of history, no auth)
- **Cross-chain data:** Approximate, from public block explorers. Clearly labeled.
- **No synthetic data:** Earlier versions of this project included estimated agent activity and stablecoin breakdowns. Those have been removed. If we can't verify it, we don't show it.
- **30-day averages:** All growth rates use 30-day window averages, not single-day endpoints.

## Limitations

- **Agent thesis is unverifiable from public APIs.** We cannot distinguish `*.agent.near` accounts from regular accounts without BigQuery access.
- **Volume attribution is unknown.** The $190M/day could be economic settlement or custodial reshuffling.
- **Cross-chain comparison data is approximate.** Only NEAR figures come from a verified API.
- **The `unique_contracts` field** from NEARBlocks may not measure new contract deploys specifically.
- **Fees rose 2.6x** during the window ($0.0025 → $0.0066). The "sub-cent fees" advantage is real but less dramatic than it appears.
